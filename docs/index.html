A Free, Open-Source Alternative

To PDANet and EasyTether

Share your Android device's internet connection with your Windows or Linux computer — no root required, no subscriptions, and a fully open source code from top to bottom.

Get Started Learn More

Current Features (v0.6.1)

USB Tethering

Fast and reliable connection via USB cable

WiFi Tethering

Wireless connection over the local network, with mDNS auto-discovery

Bluetooth Tethering

RFCOMM with token authentication (Linux desktop client; the Windows client has no Bluetooth)

No Root, No Phone VPN

A userspace relay opens ordinary phone sockets for the computer's connections, so the phone keeps its own internet

Cross-Platform Desktop

Native Windows and Linux clients

Secure by Default

Token authentication on WiFi and Bluetooth, WiFi encrypted by default (TLS 1.3 pinned to the pairing token), auto-reconnect with exponential backoff

Get Started

sudo ./scripts/quick-start-linux.sh
# PowerShell as Administrator

Cost Free, no subscriptions Paid / subscription tiers

Tech stack Kotlin (Android) + Rust (Desktop) Proprietary
Extensible Yes — open protocol, contributions welcome No
